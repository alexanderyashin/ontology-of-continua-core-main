# OC Core 1.3.3 Modern Science Comparator Scope

This directory contains source-backed comparator support for the modern-science superiority register.

Policy:

- Primary or source-backed references may establish incumbent modern-science capacity.
- Absence from a capsule is never used as novelty, priority, or superiority evidence.
- OC superiority is certified only when a lane has an incumbent source, an OC artifact, a predeclared metric, a comparator baseline, a held-out or prospective split, a negative control, a falsifier, and an independently replayable result.
- Current OC Core 1.3.3 material remains blocked for broad modern-science superiority. Existing target-blind rows support only bounded reconstruction claims.
