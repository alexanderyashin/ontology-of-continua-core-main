# OC Core 1.4 Public Review Payload

This branch is a no-send review staging payload for OC Core 1.4. It contains the reader-facing manuscript surfaces, reproducibility metadata, formal/proof ledgers, validation packets, data manifests, and benchmark/replay artifacts intended for external inspection.

Excluded from this branch: non-release authoring material, non-public review traces, journal portal materials, GitHub release actions, DOI actions, and Zenodo upload actions.

Promotion boundary: this payload is prepared for review only. Tagging, Zenodo deposition, journal submission, or public release announcement require explicit approval after the final release gate.
