# OC14 Literature Ingestion Protocol

Pipeline: collect -> deduplicate -> classify -> rank -> summarize -> extract claims -> map to OC -> CandidatePatch -> benchmark impact -> IP screen -> owner review queue.

Allowed sources: arXiv, Crossref, Semantic Scholar, OpenAlex, PubMed/Europe PMC, DOAJ/CORE/BASE, journal RSS, GitHub search, weak public blogs, and patent search. Paywall bypass and proprietary copying are forbidden.
