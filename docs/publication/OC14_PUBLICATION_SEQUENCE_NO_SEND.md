1. IP_SCREEN_COMPLETE.
2. PATENTABLE_CONTENT_REMOVED_OR_FILED.
3. AUTHORSHIP_CONFIRMED.
4. CLAIM_REGISTER_LOCKED.
5. REPRODUCIBILITY_PACKAGE_READY.
6. OWNER_APPROVAL_GRANTED.
