# Ontology of Continua: accepted formal-source edition

Edition status as of 2026-10-11: exact custody projection of the accepted
2026-10-10 kernel-r6 source cut; independent portable-package build pending.

Ontology of Continua studies systems through continuations, distinctions,
observation, composition and their explicit hypotheses. This packet preserves
998 named Lean source modules: 992 inherited slots (four accepted revisions)
and six admitted extension slots. Module identities and hashes are recorded in
SOURCE_MANIFEST.json. OCQualifiedEdition.lean coimports the exact roster.

The accepted source audit reports no owned axioms, sorryAx or nonstandard
transitive foundations; Classical.choice, Quot.sound and propext are allowed.
Source transport does not itself establish empirical applicability, scientific
novelty, full ordinary reader-proof review or qualification of changed wiring.

Lean is pinned to 4.28.0. Root and first-party package recipes are provided.
No cache, database, private production machinery or third-party source is copied.
DEPENDENCIES.json records exact observed transitive Git pins and the local
Mathlib content fingerprint. Its upstream revision/restoration is unresolved.
After exact dependency restoration and separate qualification, the intended
check is `lake build OCQualifiedEdition`. It has not been run for this packet.
