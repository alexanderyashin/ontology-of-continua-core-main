\subsubsection{\texorpdfstring{$K_0$}{K_0} Übersicht}
\label{sec:k0-overview}

Die Ebene $K_0$ stellt das prästrukturelle Fundament aller Kontinua dar.
Es handelt sich nicht um eine physikalische oder geometrische Domäne, sondern um das logische Substrat
definiert die \emph{Bedingungen der Möglichkeit} für jedes Kontinuum $K_x$.
Es stellt den Metadruck, die Zulässigkeitsbeschränkungen und die Logik bereit
Überlegenheit (Axiom~0.3) und die universellen Regeln, die welche regeln
Strukturen können vorhanden sein.

$K_0$ selbst besitzt weder die herkömmlichen Achsen noch die Geometrie
Abmessungen.
Stattdessen heißt es:
\begin{itemize}
    \item die Metagesetze $\mathcal{L}$, die die strukturelle Kohärenz bestimmen,
    \item der Möglichkeitsraum $\mathcal{P}$ für alle Kontinua,
    \item der Metadruck, der die Entstehung von Unterschieden vorantreibt,
    \item die universellen Schwellenwerte, die Zulässigkeit und Zusammenbruch definieren,
    \item die Rekursionsregeln $K_x \mapsto M_x \mapsto K_{x+1}$.
\end{itemize}

Seine Hauptfunktion ist die \textbf{logische Steuerung} aller tieferen Dinge
Ebenen.

% ================================================================
\subsubsection{Zustandsraum \texorpdfstring{$\Omega(K_0)$}{\Omega(K_0)}}

$\Omega(K_0)$ besteht aus allen zulässigen Konfigurationen des Paares
\[
(\mathcal{P}, \mathcal{L}),
\]
wobei $\mathcal{P}$ der Metabereich möglicher Strukturen und ist
$\mathcal{L}$ ist das System von Metagesetzen, die Kohärenz erzwingen.

Da $K_0$ vorgeometrisch ist, ist $\Omega(K_0)$ kein metrischer Raum, sondern
eine abstrakte Menge mit den folgenden Eigenschaften:
\begin{enumerate}
    \item $\Omega(K_0)$ enthält alle möglichen Spezifikationen von
          strukturelle Zwänge, die die Existenz von Kontinua ermöglichen.
    \item $\Omega(K_0)$ hat keine interne Topologie, es sei denn, es wird durch induziert
          Einschränkungen in $\mathcal{L}$.
    \item Jedes $\Omega(K_x)$ für $x \ge 1$ ist eine \emph{Teilmenge} von
          $\Omega(K_0)$:
          \[
              \Omega(K_x) \subseteq \Omega(K_0).
          \]
\end{enumerate}

Es gibt keine kontinuierliche Entwicklung innerhalb von $\Omega(K_0)$; es definiert
\emph{Bedingungen}, keine dynamischen Trajektorien.

% ================================================================
\subsubsection{Grenze \texorpdfstring{$\partial\Omega(K_0)$}{\partial\Omega(K_0)}}

Die Grenze von $K_0$ besteht aus allen Metakonfigurationen, die verletzen
interne Kohärenzbedingungen der Metagesetze $\mathcal{L}$.

Eine Konfiguration $(\mathcal{P},\mathcal{L})$ liegt auf $\partial\Omega(K_0)$, wenn:
\begin{itemize}
    \item die Gesetze widersprechen sich,
    Die Zulässigkeit von \item bricht zusammen ($\mathcal{P}$ wird leer),
    \item-Rekursionsregeln werden undefiniert,
    Die strukturellen Konsistenzbedingungen von \item können nicht aufrechterhalten werden.
\end{itemize}

Das Überschreiten von $\partial\Omega(K_0)$ entspricht der logischen Unmöglichkeit
eines Kontinuums.

% ================================================================
\subsubsection{Achsen \texorpdfstring{$A(K_0)$}{A(K_0)}}

$K_0$ hat keine geometrischen Achsen. Stattdessen enthält es:
\begin{itemize}
    \item abstrakte Achsen von \emph{Möglichkeit},
    \item Zulässigkeitsachsen, die regeln, welche Strukturen hergestellt werden können,
    \item-Metaachsen, die die logischen Abhängigkeiten zwischen Ebenen definieren.
\end{itemize}

Formal ausgedrückt:
\[
A(K_0) = \{ \text{Dimensionen der zulässigen Strukturvariation} \}.
\]

Dies sind die ultimativen Quellen aller späteren Achsen:
\[
A(K_x) \subseteq A(K_0).
\]

\subsubsection{Potentiale \texorpdfstring{$P(K_0)$}{P(K_0)}}

Potenziale bei $K_0$ beschreiben Metabedingungen, die Kontinua in Richtung treiben
Struktur:
\[
P(K_0) = \{ \text{Drücke, Einschränkungen, logische Gradienten} \}.
\]

Dazu gehören:
\begin{itemize}
    \item Metapressur (Axiom 0.z),
    \item Druck zur Strukturierung,
    \item Druck zu kompatiblen Unterschieden,
    \item Druck in Richtung nicht leerer zulässiger Räume.
\end{itemize}

Diese Potenziale sind keine numerischen Energien, sondern logische Intensitäten.

\subsubsection{Schwellenwerte \texorpdfstring{$\Theta(K_0)$}{\Theta(K_0)}}

Schwellenwerte bei $K_0$ entsprechen logischen Haltepunkten:
\[
\Theta(K_0) = \{ \Theta_{\mathrm{coh}}, \Theta_{\mathrm{adm}},
                 \Theta_{\mathrm{meta}} \}.
\]

Beispiele:
\begin{itemize}
    \item $\Theta_{\mathrm{coh}}$: minimale Kohärenz von Metagesetzen,
    \item $\Theta_{\mathrm{adm}}$: minimaler nichtleerer Möglichkeitsraum,
    \item $\Theta_{\mathrm{meta}}$: minimale Unterstützung für Rekursion.
\end{itemize}

Wenn ein Schwellenwert verletzt wird, kann bei keinem $K_x$ ein Kontinuum existieren.

% ================================================================
\subsubsection{Flüsse \texorpdfstring{$J(K_0)$}{J(K_0)}}

Bei $K_0$ gibt es keine physischen Flüsse.
$J(K_0)$ enthält stattdessen:
\begin{itemize}
    \item Zulässigkeitsflüsse,
    \item Flüsse logischer Abhängigkeit,
    \item Weitergabe von Einschränkungen,
    \item-Metaflüsse, die beschreiben, welche Strukturen andere generieren können.
\end{itemize}

Diese Strömungen prägen den Raum möglicher Kontinuen, korrespondieren aber nicht miteinander
zur Zeitentwicklung.

\subsubsection{Zyklen \texorpdfstring{$C(K_0)$}{C(K_0)}}

Zyklen bei $K_0$ entsprechen:
\begin{itemize}
    \item Festkomma-Konsistenzzyklen,
    \item Metastabilitätsschleifen der Zulässigkeit,
    \item selbstreferenzielle Abschlusszyklen in $\mathcal{L}$.
\end{itemize}

Ein Zyklus existiert, wenn:
\[
\Pi(C) > \Theta_{\mathrm{coh}},
\]
wobei $\Pi(C)$ die „Leistung“ des Metazyklus ist (Stabilität der Rekursivität).
Schließung).

Es gibt keine zeitlichen Zyklen; das sind rein logische Zyklen.

\subsubsection{Zeit \texorpdfstring{$\tau(K_0)$}{\tau(K_0)}}

Bei $K_0$ existiert keine Zeit.

Satz „Entstehung der Zeit aus C-Zyklen“ (Physics Run):

Die Zeit entsteht, wenn $\Omega(K_2)$ einen nicht abbaubaren Kreislauf enthält
$C$ mit:
\[
\Pi(C) > \Theta_{\mathrm{Zeit}}.
\]

Also:
\[
\tau(K_0) \;\text{undefiniert}.
\]

\subsubsection{Kontinuität \texorpdfstring{$k(K_0)$}{k(K_0)}}

Kontinuität misst die Zulässigkeit aller Kontinua:
\[
k(K_0) =
H(\Omega(K_0)) \cdot
k_A(K_0) \cdot
k_{\mathrm{coh}}(K_0),
\]
wo:
\begin{itemize}
    \item $H(\Omega(K_0)) = 1$ wenn $\Omega(K_0)\neq\emptyset$, sonst $0$,
    \item $k_A(K_0)$ misst die Vielfalt der zulässigen Achsen,
    \item $k_{\mathrm{coh}}$ misst die Kohärenz des Metagesetzes.
\end{itemize}

Wenn $k(K_0)=0$, kann kein Kontinuum auf einer höheren Ebene existieren.

\subsubsection{Strukturelle Spannung \texorpdfstring{$T(K_0)$}{T(K_0)}}

Strukturelle Spannung ist:
\[
T(K_0) = T(\mathcal{P}, \mathcal{L}),
\]
stellt den Grad der Inkompatibilität innerhalb von Metagesetzen oder zwischen diesen dar
Metagesetze und zulässige Strukturen.

Hohe Spannung kann:
\begin{itemize}
    \item zulässige Mengen reduzieren,
    \item erzeugt inkompatible Zweige,
    \item Collapse $\Omega(K_0)$.
\end{itemize}

% ================================================================
\subsubsection{Energie \texorpdfstring{$E(K_0)$}{E(K_0)}}

Bei $K_0$ gibt es keine physikalische Energie.
Stattdessen:
\[
E(K_0) = E_{\mathrm{meta}},
\]
ein formales Maß für die interne Unterstützung konsistenter Strukturen:
\[
E_{\mathrm{meta}} \propto \text{Kohärenz von }\mathcal{L}.
\]

\subsubsection{Operatoren auf \texorpdfstring{$K_0$}{K_0} (\texorpdfstring{$\Psi$}{\Psi}, \texorpdfstring{$\Phi$}{\Phi}, \texorpdfstring{$\Lambda$}{\Lambda}, \texorpdfstring{$U$}{U}, \texorpdfstring{$\Chi$}{\Chi})}

Operatoren bei $K_0$ regeln Zulässigkeit und Rekursion:

\begin{itemize}
    \item $\Psi$: Operator zur Ebenenerstellung
          \[
          \Psi: K_x \mapsto M_{x+1}
          \]
    \item $\Phi$: Operator der Metaraumentwicklung

          \]
    \item $\Lambda$: Einschränkungsoperator, der $\mathcal{L}$ erzwingt
    \item $U$: Operator der strukturellen Vereinheitlichung
    \item $\Chi$: Operator der logischen Verzweigung (Axiom~21)
\end{itemize}

Diese Operatoren definieren das Rückgrat der vertikalen Rekursion.

          chemische, biologische, kognitive und soziale Systeme,
    \item Allgegenwärtigkeit struktureller Rekursionsmuster,

\end{itemize}

\subsubsection{Zusammenbruch und Tod von \texorpdfstring{$K_0$}{K_0}}

Ein Zusammenbruch tritt auf, wenn:
\[
\Omega(K_0) = \varnothing.
\]

Dies entspricht:
\begin{itemize}
    \item widersprüchliche Metagesetze,
    \item logisch inkonsistenter Möglichkeitsraum,
    \item nicht unterstützbare Rekursion $\Psi$ oder $\Phi$,
    \item Verletzung von $\Theta_{\mathrm{coh}}$ oder $\Theta_{\mathrm{adm}}$.
\end{itemize}

Wenn $K_0$ kollabiert, kollabieren alle Kontinua gleichzeitig.

\subsubsection{Falschbarkeit von \texorpdfstring{$K_0$}{K_0}}

Die folgenden Vorhersagen sind falsifizierbar:
\begin{enumerate}
    \item Universelles Vorhandensein von Schwellenwerten $\Theta$ auf allen Ebenen.
    \item Irreversibilität des Dimensionswachstums (Satz~1).
    \item Entstehung der Zeit nur bei $K_2$ durch Zyklen.
    \item Existenz der universellen Rekursion $K_x\to M_x\to K_{x+1}$.
\end{enumerate}

Das Versagen eines dieser Verhaltensweisen verfälscht empirisch $K_0$.

\subsubsection{Verzweigung / ontologische Position von \texorpdfstring{$K_0$}{K_0}}

Basierend auf Axiom~21 (Ontologische Verzweigung) ist $K_0$ der Wurzelknoten von
ontologischer Verzweigungsbaum:
\[
K_0 \rightarrow K_1 \rightarrow K_2 \rightarrow \dots \rightarrow K_{12}.
\]

Alle Zweige müssen mit $\mathcal{L}$ kompatibel bleiben; inkompatibel
Zweige sterben durch Zusammenbruch der Zulässigkeit.

\subsubsection{Beziehung zu M-Räumen}

$K_0$ definiert die Zulässigkeit und Struktur aller Metaräume:
\[
M_x \subseteq \Omega(K_0).
\]

Umgekehrt:
\[
K_x \subseteq M_x,
\qquad
M_x \subseteq \Omega(K_{x+1}),
\]
was $K_0$ zum einzigen vereinigenden Superraum für das Ganze macht
Hierarchie.
