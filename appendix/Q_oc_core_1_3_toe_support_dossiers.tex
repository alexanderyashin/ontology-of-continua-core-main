\section{Unified Synthesis Support Dossiers}
\label{sec:oc-core-1-3-synthesis-support-dossiers}

The main unified-synthesis section remains the canonical synthesis unit in the
numbered Core~1.3 sequence of the manuscript.
The material gathered here is retained only as level-wise evidence support: it
keeps the K-anchored proof, empirical, falsifier, and packet dossiers
available inside the flagship volume without repeating the synthesis-section
introduction, release gate, or synthesis prose.
Section~\ref{sec:oc-core-1-3-unified-synthesis} uses the generated synthesis
surface for the main K-level exposition. The dossier files included here are
included exactly once in the English platinum master, through this appendix
wrapper. The main chapter and this appendix therefore play different roles:
the chapter states the synthesis, while this appendix carries the level-wise
support dossiers. Compatibility support files are not input directly by the
English platinum master. A build variant must therefore choose either the
compatibility synthesis-support master or this appendix wrapper, never both.
The full DFS compatibility stream still records those compatibility entries for
auditability, but the platinum master does not input the compatibility
synthesis-support master. The constants-and-parameters apparatus remains
available at Appendix~\ref{app:synthesis-constants-and-parameters} because
Appendix~\ref{app:klevels-tables} inputs \occode{appendix/toe_data.tex} as its
nested parameter-law block; it is not a separate top-level appendix in the
platinum spine.
