\section{Reviewer Navigation Matrix and Audit Checklist}
\label{sec:oc13-reviewer-navigation}

This appendix is written for the reviewer who wants to audit the monograph as efficiently as
possible. It is not a replacement for the main text. It is a map that tells the reviewer where a
specific doubt should be tested first and what kind of evidence would count as a meaningful
objection.
In this appendix, \emph{monograph} is the canonical term for the English
flagship volume, and \emph{journal core} is the canonical term for the shorter
bounded extraction from that volume. \emph{Release} refers to the outward
package that also contains supporting surfaces, PDFs, assets, and companion
dossiers.
Concrete artifact classes are as follows: \emph{surfaces} are the
release-bundled \occode{editorial/*_latest.json} projections; \emph{companion dossiers} are the
generated dossier packages under \occode{editorial/dossier_packages/};
\emph{assets} are the released figures and tables under \occode{assets/}; and
the \emph{archival PDF witness} is the prior Core~1.2 PDF named in the
journal-core provenance route in Appendix~\ref{sec:oc13-journal-core-bridge}:
\emph{Ontology of Continua --- Core v1.2.0}.

\subsection{A compact reading order for different reviewer temperaments}

\paragraph{Fast hostile reviewer.}
Read the abstract, theorem roadmap, relevant theorems and corollaries, the worked examples,
and the journal-core bridge appendix. Return to this matrix only to choose a
new route after that first pass. This route should reveal immediately
whether the release is larger than necessary, narrower than promised, or contains silent scope
drift.

\paragraph{Formal mathematical reviewer.}
Read the model, results, axioms, operators, collapse/rebirth material, hierarchy chapter,
notation appendix, and source-audit chapter. The decisive question is whether the derived bounded
claim can be reconstructed from the stated source-native rows without informal supplementation.

\paragraph{Generalist scientific reviewer.}
Read the introduction, reader guide, theorem roadmap, worked examples, discussion, conclusion,
and then return to the formal chapters selectively. The decisive question here is whether the
volume explains itself honestly enough that scientific judgment can precede local notation
mastery.

\subsection{Why this appendix belongs in the release}

Large frameworks often lose trust because reviewers are forced to reconstruct the author's intent
instead of being shown where to test it. This appendix is a direct answer to that problem. It is
not rhetorical self-defense. It is an invitation to audit the monograph in a precise order.
If the release survives that order, it becomes easier to trust the rest of the monograph. If it fails,
the failure should appear early and explicitly.
