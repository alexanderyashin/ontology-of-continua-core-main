maintenance mode. The domain notes make explicit which command constitutes the
lawful next step, which acceptance rule that command is meant to protect, and

\paragraph{Mathematics.}
Validation remains \occode{PASS}, and the lane is executable now because the
command path is purely deterministic. Caseset readiness is 0 parameterized out
of 0 cases with a minimum requirement of 31, while coverage and parameterization
remain \occode{NOT_REQUIRED}. Promotion survives only if no replay divergence
and no surviving counterexample appear. The lawful command is
\occode{logion/k7/spe/orchestrator/science/run_claim_simulations_v1.py}. The
required prerequisites remain the pinned source route, the benchmark manifest,
the numerical packet specification, the replay harness, and an explicit
falsifier. Blocking ids: none. No institute-run wave is required.

\paragraph{Physics.}

in expansion mode. Caseset readiness is 30 parameterized out of 30 cases, with

\occode{INSTITUTE_RUN::PHYSICS::WAVE_1A} remains on stand-by, not active.
