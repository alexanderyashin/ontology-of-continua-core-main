# OC Core 1.3.3 Simulations

This layer is a no-send simulation and reproducibility companion for OC Core 1.3.3 v12.

The simulations are deterministic illustration and regression fixtures. They do not provide
empirical validation or prediction support by themselves.

- role ledger: `simulations/OC_SIMULATION_ROLE_CLASS_LEDGER_latest.json`
- expected outputs: `simulations/OC_SIMULATION_EXPECTED_OUTPUTS`
- failure cases: `simulations/OC_SIMULATION_FAILURE_CASES.md`
