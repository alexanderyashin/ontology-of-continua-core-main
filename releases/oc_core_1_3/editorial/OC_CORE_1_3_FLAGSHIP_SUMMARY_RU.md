Используя проверенный исходный корпус Core 1.2, статья показывает: когда континуум теряет всякую допустимую реализацию, исходный континуум мертв; любой переживший след есть остаток; любое более позднее живое продолжение на этой основе есть перерождение, а не сохранение исходного объекта. Рукопись сознательно сохраняет режим строгого отказа и не втягивает неперепроверенные семейства теорем в положительное тело.
