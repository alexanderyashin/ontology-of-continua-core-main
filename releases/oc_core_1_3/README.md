# OC Core 1.3 Release Bundle

This folder prepares the dual-track OC Core 1.3 science release for the open foundation publication route.

- `monograph/` contains the English master monograph built directly from the public LaTeX source corpus. Russian and German Core 1.3.1/1.3.x draft reading material may remain in the repository as deferred, repository-only material; it is not part of the English Zenodo upload manifest.
- `journal_core/` contains the shorter English journal-facing extraction. Russian/German companion material is deferred until a separate translation-review pass accepts it for publication.
- `manuscripts/` keeps the English flagship-manuscript convenience surface for readers and downstream journal packaging. The journal-core article remains staged separately under `journal_core/`.
- `editorial/science_sources/` is the source-owned science corpus for the release. The remaining `editorial/` surfaces and `assets/` provide support, projection, review, and packaging material derived from that corpus.
- `editorial/domain_packets/` contains the packetized hard-closure domain dossiers with benchmark routes, replay commands, and falsifier definitions.
- `editorial/DOMAIN_EMPIRICAL_EXECUTION_PROTOCOLS_latest.json`, `editorial/DOMAIN_BENCHMARK_DATASET_MANIFEST_latest.json`, `editorial/DOMAIN_REPLAY_REPORTS_latest.json`, and `editorial/INSTITUTE_RUN_MEASUREMENT_PROGRAM_latest.json` expose the hybrid-escalation evidence bar, pinned benchmark datasets, replay packets, and the institute-run fallback waves.
- `editorial/OC_CORE_1_3_MEASUREMENT_WAVE_PACKETS_latest.json` is the release-side projection of the measurement-wave registry whose governance/status surface is `logion/k0/governance/status/OC_CORE_1_3_MEASUREMENT_WAVE_PACKETS_latest.json`. In the current bundle it records no active stand-by institute-run packets; future wave files must be added at the source surface before any README path claims they are materialized.
- The monograph source package includes the reader guide, source-audit chapter, foundational consistency dossier, revision law, minimality ablation ledger, alternative-model competition matrix, and the bounded compression benchmark used to keep the proof machinery explicit.
