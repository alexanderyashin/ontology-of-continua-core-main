# OC Core 1.3 Release Bundle

This folder prepares the dual-track OC Core 1.3 science release for the open foundation publication route.

- `monograph/` contains the English master monograph built directly from the public LaTeX source corpus, plus Russian and German guided reading editions that embed the same proof-bearing master volume behind localized front matter and reading guidance.
- `journal_core/` contains the shorter journal-facing extraction, with English as the master lane and Russian/German as full companion translations.
- `manuscripts/` keeps compatibility aliases for the journal-core PDFs and Markdown sources.
- `editorial/` and `assets/` contain the outward support package shared across the same scientific version.
- `editorial/OC_CORE_1_3_SCIENCE_SPOT_latest.json` is the canonical scientific authority for Core 1.3; the foundational dossier, empirical execution surfaces, validation matrix, command board, and generated science chapters now project from this SPOT.
- `editorial/OC_CORE_1_3_FULL_SCIENTIFIC_CLOSURE_PROGRAM_latest.json`, `editorial/OC_CORE_1_3_UNIFIED_SCIENCE_ATLAS_latest.json`, `editorial/OC_CORE_1_3_PROOF_OBLIGATION_REGISTRY_latest.json`, `editorial/OC_CORE_1_3_HOSTILE_REVIEW_BACKLOG_latest.json`, `editorial/OC_CORE_1_3_DOMAIN_CLOSURE_BUNDLE_REGISTRY_latest.json`, `editorial/OC_CORE_1_3_PHASE1_CLOSED_CORE_DOSSIER_latest.json`, `editorial/OC_CORE_1_3_TOE_SYNTHESIS_latest.json`, and `editorial/OC_CORE_1_3_PRACTICAL_UTILITY_ATLAS_latest.json` carry the long-horizon closure program, the cross-domain atlas scaffold, the load-bearing proof obligations, the hostile-review blockers, the per-claim closure bundles, the first-class Phase 1 closed-core dossier, the manuscript-facing unified-science closure surface, and the practical-use and serious-comparison authority for the flagship monograph. The `TOE` filename is retained for compatibility; public TOE naming is only lawful after final `PASS`.
- `editorial/dossier_packages/` materializes the execution cockpit on disk: one dossier package per closure bundle, one formal dossier per hostile-review blocker, and one consolidated package for the Phase 1 closed core.
- `editorial/domain_packets/` contains the packetized hard-closure domain dossiers with benchmark routes, replay commands, and falsifier definitions.
- `editorial/DOMAIN_EMPIRICAL_EXECUTION_PROTOCOLS_latest.json`, `editorial/DOMAIN_BENCHMARK_DATASET_MANIFEST_latest.json`, `editorial/DOMAIN_REPLAY_REPORTS_latest.json`, and `editorial/INSTITUTE_RUN_MEASUREMENT_PROGRAM_latest.json` expose the hybrid-escalation evidence bar, pinned benchmark datasets, replay packets, and the institute-run fallback waves.
- `publication_ready/oc_core_1_3_flagship/measurement_waves/` materializes stand-by institute-run wave packets with the lawful command chain and uncovered benchmark families.
- The monograph source package includes the reader guide, source-audit chapter, foundational consistency dossier, revision law, minimality ablation ledger, alternative-model competition matrix, the bounded compression benchmark used to keep the proof machinery explicit, a generated unified-science closure chapter with explicit K0-K12 numerical rows that is promoted to `Theory of Everything Synthesis` only after the final validator passes, and a dedicated practical-consequences chapter plus appendix that answer what the framework now lets the reader predict, do, compare, and operationalize.
