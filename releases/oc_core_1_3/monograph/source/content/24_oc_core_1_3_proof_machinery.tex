\section{Proof Machinery, Revision Law, Competition, and Compression}

The present release does not treat proof as a single binary flag. Its proof
machinery is projected from one scientific authority so that foundational
consistency, empirical bridge status, revision law, proof obligations,
competition pressure, and bounded compression metrics remain aligned under one
scientific verdict. This layer is what prevents the Core from becoming
rhetorical rubber: the same promotion law that constrains runtime status now
constrains the monograph itself.
