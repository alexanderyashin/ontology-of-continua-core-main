\section{Атлас рисунков}
\label{sec:oc-core-1-3-figure-atlas}

Это приложение сохраняет унаследованный корпус рисунков внутри флагманского
тома, но не перегружает центральный маршрут чтения. Рисунки остаются частью
монографии; они просто перенесены в отдельный visual atlas.
