# Checklist

- [x] Manuscript elements include title, authors, affiliations, abstract, author summary, introduction, results, discussion, methods, acknowledgements, references, supporting information, figures, and tables.
- [x] Initial file may be a single PDF; revised files separate text, figures, and supporting information.
- [x] Headings are limited to three levels, text should be double-spaced, and page plus continuous line numbers are required.
- [x] Author Summary is 150 to 200 words, non-technical, first-person, and distinct from the scientific abstract.
- [x] Data and code underlying findings must be made available with explicit statements.
