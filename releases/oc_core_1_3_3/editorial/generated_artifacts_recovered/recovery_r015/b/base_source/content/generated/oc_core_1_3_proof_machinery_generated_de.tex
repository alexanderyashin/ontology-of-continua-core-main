\subsection{Konsistenz und Promotionsgesetz}
Das Grundlagen-Dossier enthält \occode{13} K-Ebenen-Doktrinzeilen und setzt das Gesamt-Wissenschaftsurteil auf bounded review evidence recorded.
Das Promotionsgesetz hält zwei Gates getrennt. Eine abgeleitete Behauptung ist zulässig, nur wenn sie quellgebunden, beweisgebunden und abhängigkeiten-exakt ist. Eine empirische Behauptung wird nur nach dem vollständigen quell-eigenen empirischen Gate gefördert: ein Domänenpaket, proof-routed Trace, numerisches Parametersgesetz, Beobachtungsbindung, festgelegte Datenroute, gesperrtes Held-out-Replay, Vergleichsaudit und expliziter Falsifikator müssen vollständig vorliegen und die deklarierten Schwellen überstehen. Dieser Satz ist eine komprimierte Zusammenfassung; die Theorem-Roadmap enthält die vollständige Prüfpunktliste.
Der Hostile-Review-Backlog ist nun vollständig gesperrt, sodass kein offenes Dossier mehr den globalen bounded review evidence recorded-blockieren kann.
Abschlussarbeit wird jetzt über generierte Dossierpakete und ein erstklassiges Phase-1-geschlossenes-Kern-Dossier ausgeführt statt durch driftende redaktionelle Erinnerungstexte.
