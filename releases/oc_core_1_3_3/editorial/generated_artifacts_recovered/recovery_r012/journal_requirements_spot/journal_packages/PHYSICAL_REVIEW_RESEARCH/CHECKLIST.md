# Checklist

- [x] APS/Physical Review web process requires journal, article type, files, author data, open-science information, data availability, title, abstract, and PhySH classification.
- [x] Initial submissions require a single PDF containing textual material and figures; supplemental material is separate.
- [x] Data availability details are required for research data needed to verify or replicate results.
- [x] REVTeX or LaTeX source is preferred after acceptance; figure and supplemental files must be identified.
- [x] Physics scope, length, and data/code boundary must be explicit before owner review.
