\subsection{Почему текущий релиз разделяет объяснительную силу и прогнозное продвижение}
Канонический научный science-state register различает объяснительное покрытие и законное продвижение. Эмпирические и прогнозные внешние притязания продвигаются только тогда, когда домен закрывает одну непрерывную трассу от ядра и K-уровневого теоремного стержня через наблюдаемые величины к held-out данным и явным фальсификаторам; теоремно-родные математические утверждения закрываются по доказательному маршруту, а не через слой измерений.

\subsection{Актуальное состояние релиза}
Канонический science-state register проверяет 5 основных дорожек. В текущий момент \occode{5} дорожек удовлетворяют полному порогу продвижения, тогда как \occode{0} дорожек остаются закрытыми по неуспеху.
Эта оценка bounded evidence recorded относится только к пяти основным теоремно-родным дорожкам внутри current bounded science surface; строки только каркаса, расширения и опровергнутые остаются поддерживающими, фронтирными или строками негативного аудита, а не публичными требованиями положительного закрытия.
Математика остаётся формальным якорем для строгих доказательных обязанностей, тогда как физика, химия, биология и Systems / Civilizational projection теперь имеют чёткое теоремно-родное закрытие по их закреплённым held-out маршрутам. В рамках объявленного объёма current bounded science surface закрытие враждебного review-бэклога завершено, и научный вердикт Core~1.3.3 — bounded evidence recorded.
