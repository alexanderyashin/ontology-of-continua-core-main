\subsection{Practical value and support boundary}
The practical utility atlas currently tracks bounded review protocols, frontier-program rows, and hypothesis-only rows; it does not promote operational proof merely from row presence.
The domain lanes are retained as bounded review protocols under explicit theorem, data-route, and falsifier discipline; the cross-domain route-selection lane is bounded as a route-selection example and is used for packet selection rather than as a domain-level theorem claim.
Its practical value in this release is methodological: it shows how packet selection, residual checks, anomaly screens, state-transition audits, regime-shift monitors, and cross-domain route selection should be bounded before any operational claim is promoted.
The atlas also keeps 3 frontier-program rows and 1 hypothesis-only row explicit so practical ambition does not masquerade as finished closure.
