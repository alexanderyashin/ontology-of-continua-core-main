\section{Эмпирический бар исполнения и протоколы реализации}
\label{sec:oc-core-1-3-empirical-execution-protocols}

Эта глава описывает эмпирический бар исполнения релиза. Она определяет, какие
источники-авторитеты, отложенные схемы дизайн-экспериментов, политике
бенчмаркинга, допустимые отклонения и условия фальсификации законно
проверяют продвигаемые пакеты, и отделяет ограниченную эмпирическую
поддержку от риторического преувеличения. Здесь не повторяется
скелет теорем, полный реестр поддержки доказательством или полный перечень
датасетов; описывается, как пакеты на практике подвергаются проверкам.

Научный авторитет для этого эмпирического бара даёт канонический
evidence-state summary, \occode{the public evidence-state summary}, закреплённый в репозитории
по путиnamed public evidence row.
Эта глава приводит этот источник в форму, ориентированную на читателя, чтобы
бар исполнения, дисциплина воспроизведения и вердикт продвижения опирались на
единую допустимую границу источника. Ниже сгенерированный раздел выводит
точные значения the repository checksum field и \occode{the release timestamp field}
для версии evidence-state summary, использованной в данной сборке.
