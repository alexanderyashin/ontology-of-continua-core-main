\section{Единый научный синтез}
\label{sec:oc-core-1-3-unified-synthesis}
Финальный статус релиза единого синтеза: bounded review evidence recorded.

В этой главе изложен продвинутый синтез, выведенный из канонического evidence-state summary. Она содержит законно продвинутый единый синтез с явными законами параметров K0--K12, числовыми рядами, фальсификаторами и сводками эмпирических предсказаний на отложенной выборке.
Название и область этой главы соответствуют канонической записи evidence-state summary; открывающий абзац-шлюз фиксирует статус выпуска, а затем ряды уровней K дают теоремные утверждения, законы параметров, привязки наблюдаемых, числовые подвыборки, фальсификаторы и привязки пакетов, необходимые для проверяемости синтеза.

\subsection{Итоговый шлюз выпуска единого синтеза}
Точный валидатор: \occode{BOUNDED_SYNTHESIS_REVIEW_RECORDED}.
Шлюз выпуска теперь сообщает \occode{0} домены только-моста, \occode{0} блокеры враждебного обзора, и интегрируемость: bounded review evidence recorded.
Итоговое правило продвижения сформулировано параллельно: каждый эмпирический базовый домен должен быть теоремно-нативным; суммарное число доменных только-моста должно быть нулевым; суммарное число блокеров враждебного обзора должно быть нулевым; единый атлас и пакет интегрируемости должны проходить; а числовые ряды K0--K12 должны оставаться явными.
В каноническом evidence-state summary не осталось блокеров выпуска.
