# Checklist

- [x] Package must include manuscript, cover letter, supporting information when needed, graphics/tables, declarations, data/code statement, and author information.
- [x] Chemistry or adjacent-science fit must be declared honestly; no unsupported domain claim may be introduced.
- [x] Figures, tables, references, and SI must support the text rather than decorate it.
- [x] AI assistance disclosure and human accountability must be explicit where applicable.
- [x] Source map must separate manuscript claims from evidence artifacts and reusable code/data.
