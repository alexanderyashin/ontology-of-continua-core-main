% corresponding evidence-package record
Порог эвиденса теперь привязан к каноническому science-state register, а не к плавающим сводным поверхностям. Математический якорь является replay-only: он требует детерминированного точного replay вместо маршрута бенчмарка на базе данных. Эмпирические доменные каналы требуют held-out результатов, которые проходят объявленный порог в пять сигм без увеличения числа нарушений хвоста. Простое удержание остатка в пределах допуска само по себе недостаточно для продвижения.

\subsection{Глобальный порог эвиденса}
Для эмпирических каналов порог эвиденса по умолчанию остаётся гибридной эскалацией: сначала официальные или открытые первичные данные, затем измерения, выполняемые институтами, только если соответствующее семейство наблюдаемых нельзя закрыть иным образом. Математический канал остаётся режимом только replay и закрывается детерминированным exact replay, а не маршрутом out-of-sample данных. В каждом канале дисциплина эвиденса стоит за пределами теоремно-родной трассирующей закрытости и не заменяет её.
