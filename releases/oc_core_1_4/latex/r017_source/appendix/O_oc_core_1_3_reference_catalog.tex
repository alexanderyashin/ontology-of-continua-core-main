\section{Reference Catalog of Operational Modules}
\label{sec:oc-core-1-3-reference-catalog}

This appendix-tier catalog keeps the operational overview modules that support
empirical, experimental, predictive, and falsifiability navigation. They stay
inside the flagship PDF as compact reference surfaces, while the detailed
directory-wide submodules remain source-accessible rather than being streamed
through the primary reading path.

The goal is not to hide technical material. The goal is to present it in a
reader-facing order that preserves auditability without turning the master
monograph into an uncurated dump of every auxiliary file in the repository.
