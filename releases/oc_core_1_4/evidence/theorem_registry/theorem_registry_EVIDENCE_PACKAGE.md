## Acceptance And Refusal

Acceptance requires the chapter sample, source handle, and validation surface to converge on the same limited statement. A reviewer should sample theorem statements in the mathematics chapters and verify that titles, assumptions, and dependency hints remain stable across source, PDF, and registers. The refusal condition is equally local: It fails if theorem names drift, if a theorem is cited before introduction, or if a theorem-like sentence has no registry route. A release reviewer can stop at the first missing source, over-strong sentence, or vanished boundary because the package is designed to fail cheaply.
