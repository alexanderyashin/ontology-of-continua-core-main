## Acceptance And Refusal

Acceptance requires the chapter sample, source handle, and validation surface to converge on the same limited statement. A reviewer should pick a chapter, follow its source route, and verify that the cited source family is present in the manifest. The refusal condition is equally local: It fails if a source cannot be found, if a hash is missing, or if a reader-facing claim depends on an unnamed source. A release reviewer can stop at the first missing source, over-strong sentence, or vanished boundary because the package is designed to fail cheaply.
