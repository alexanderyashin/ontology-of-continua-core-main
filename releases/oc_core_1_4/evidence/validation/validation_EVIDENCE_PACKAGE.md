## Acceptance And Refusal

Acceptance requires the chapter sample, source handle, and validation surface to converge on the same limited statement. A reviewer should compare the validation summary, the matrix, and the owner boundary, looking for self-referential PASS loops. The refusal condition is equally local: It fails if a report passes because another report says PASS without exposing the material condition. A release reviewer can stop at the first missing source, over-strong sentence, or vanished boundary because the package is designed to fail cheaply.
