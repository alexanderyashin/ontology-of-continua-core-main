## Acceptance And Refusal

Acceptance requires the chapter sample, source handle, and validation surface to converge on the same limited statement. A reviewer should ask whether the book says what a predecessor can already do before claiming a residual advantage for OC. The refusal condition is equally local: It fails if novelty is asserted without a named comparator or if a local comparator result becomes victory over a field. A release reviewer can stop at the first missing source, over-strong sentence, or vanished boundary because the package is designed to fail cheaply.
