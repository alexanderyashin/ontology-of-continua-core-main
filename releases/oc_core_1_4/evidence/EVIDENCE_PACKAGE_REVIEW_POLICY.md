# Evidence Package Review Policy

Public package: `SCIENTIFIC_PACKAGE_CURRENT`.

This file carries the common rules that used to be repeated inside every evidence-family surface. Each family file now records only the local inspection route: what that family alone tests, which public sources and chapter samples carry the load, and what specific defect would make that family fail closed.

The shared rule is simple. Evidence packages are not proof certificates, publication approval, or hidden authority. They are public review maps. A reader must be able to move from a family file to source handles, checksums, public chapter sources, artifact coverage, and the release validation surfaces without needing any excluded working files.

A family passes only when its own source handles exist, its public chapter coverage is non-empty, its source hash ledger is present, and its claim boundary is narrower than the strongest scientific statement it helps inspect. When a family is used by a chapter, the chapter must still carry the relevant proof, evidence, Lean, dataset, simulation, comparator, or owner-review boundary in ordinary reader-facing prose.

The policy also protects negative evidence. Prior failed package versions, blocked rows, and reviewer findings may be cited as diagnostic pressure, but they do not become support for final claims. If a public package line confuses owner-review readiness with public release approval, or if a source row disappears, the family is red before style or formatting is considered.
