# OC Universal Metamodel Repair Order 027

## Authority

027 supersedes 025/026 as the repair route for the universal OC claim. The 025
refutations remain valid guard rails: they refute the old overbroad two-outcome
fork, not the repaired universal metamodel.

## Root Model Change

Old rejected fork:

`unresolved contradiction -> dimension birth OR collapse`

Repaired OC-U schema:

`structured pressure in a declared description -> absorption by existing operator OR extension/refinement/new axis OR collapse of declared invariant OR underdetermined/out-of-scope until observables are supplied`

This keeps universality at the metamodel level. OC-U applies to any articulated
system-description, but domain truth still requires local observables,
constraints, operators, invariants, and evidence bindings.
