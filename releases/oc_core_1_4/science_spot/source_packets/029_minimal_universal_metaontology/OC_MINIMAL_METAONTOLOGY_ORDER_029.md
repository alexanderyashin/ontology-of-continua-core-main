minimal-metaontology package.

articulable reality, up to definitional equivalence among metamodels satisfying

## Adequacy Axioms

An adequate universal metaontology for observable/articulable reality must
support:

- observation coverage;
- distinguishability;
- state and dynamics;
- constraint pressure;
- same-description repair/absorption;
- extension/new-axis introduction;
- invariant failure/collapse;
- underdetermination when evidence or invariants are absent;
- projection non-inflation;
- evidence binding;
- compositional refinement.

These are the formal lower-bound roles. A proposed alternative that removes any
one of them is not adequate; a proposed alternative that adds roles without
changing these obligations is a non-minimal extension of the same adequacy
core.

## Core Proof Route

029 proves:

- representation: OC roles represent any articulated observation-bound system
  description satisfying the adequacy axioms;
- necessity: any adequate alternative contains all OC adequacy roles;
- uniqueness up to definitional equivalence: every adequate alternative has
  the same required role profile as OC over the adequacy-role index;
- operator minimality under typed semantic effect signatures;
- K-ladder non-collapse as a parametric rank/closure theorem;
- refutation/repair of absolute K0-K12 uniqueness;
- article non-inflation for laws, crown stones, and domain projections.
