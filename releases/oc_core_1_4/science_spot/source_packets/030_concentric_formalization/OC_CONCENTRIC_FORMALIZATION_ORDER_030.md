# OC Concentric Formalization Order 030

## Governing Rule

030 moves from the proved 029 minimal metaontology core outward through the OC
claim surface. Work proceeds by contour order:

1. center;
2. adequacy roles;
3. operators;
4. K-ladder;
5. theorem schemas;
6. laws;
7. crown stones;
8. domain projections.

Every contour must end in a proof-grade row. If an inherited OC statement is
too strong, 030 repairs it into a theorem-grade statement and records the old
statement as a counterproof guard.

## Proof Standard

Allowed final statuses:

- `PROVED_WITH_FORMAL_PROOF`
- `REFUTED_AND_REPAIRED_WITH_PROOF`
- `REJECTED_FROM_CORE_WITH_COUNTERPROOF`
- `DOMAIN_PROJECTION_PROVED_WITH_LOCAL_EVIDENCE`
- `DOMAIN_INSTANTIATION_REQUIRED_BY_THEOREM`

No final row may omit exact source statement, formal proposition, assumptions,
proof/counterproof body, falsifier check, dependency closure, verification
note, and artifact reference.
