# OC Core 1.4 Proof-Status Glossary

This glossary is normative for OC Core 1.4 public reading.

| Status | Meaning | What it does not mean |
| --- | --- | --- |
| DEFINITIONAL_SOURCE_BOUND | The item is retained as a definition or source-bound vocabulary statement. | It is not an empirical result or independent theorem. |
| REPLAY_VALIDATED | The item is supported by a replay/check route inside the release package. | It is not independent replication. |
| EMPIRICALLY_SOURCE_BOUND | The item is tied to empirical source evidence at the declared scope. | It is not a universal empirical law. |
| FORMAL_PROOF_CLOSED | The item has a declared formal proof route under stated assumptions. | It is not automatically a domain result. |
| LEAN_CHECKED | The item is mechanically checked in a Lean-facing route. | It is not broader than the encoded assumptions. |
| INDEPENDENT_REPLICATION | External replication by an independent party. | This status is not currently claimed by OC Core 1.4. |

The phrase "proof-closed" always means closed at the declared support class, not closed at every stronger class.
